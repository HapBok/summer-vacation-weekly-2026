# Week 1-2 통합 보고서

2026-06-29부터 2026-07-12까지는 본격 진도 운영 전에 학습 환경, 기록 방식, 과목 분배, DreamHack 기반 학습 구조를 테스트한 기간이다.

이 기간 동안 C/gdb 기초 실습, OPIc 루틴 테스트, 정보처리기사 정리 방식, System Hacking 입문 기록 방식을 시도했지만, 폴더와 산출물 구조가 지나치게 분산되는 문제가 있었다.

따라서 3주차부터는 DreamHack Path를 기준으로 System Hacking과 Web Hacking을 매일 병행하고, OPIc와 정보처리기사를 고정 루틴으로 운영한다.

## 1~2주차에 확보한 기반

- C 문자열, 버퍼, 정수 변환, 바이트 오더 기초 실습
- gdb를 이용한 register, stack, memory 관찰 흐름
- pwntools 기본 입출력 자동화
- DreamHack addition_quiz 풀이 기록
- OPIc/정보처리기사 루틴 테스트

## 3주차부터의 원칙

- DreamHack Path 기준으로 진도를 설정한다.
- System : Web = 2 : 1 비율을 유지한다.
- 교재는 독립 진도가 아니라 문제 풀이에 필요한 보강 자료로 사용한다.
- 매일 의미 있는 통합 산출물만 기록한다.
- 공개 저장소에는 주간 요약과 공개 가능한 write-up만 업로드한다.

## 요약

1~2주차는 테스트 기간으로 정리하고, 3주차부터 본격 진행한다.
